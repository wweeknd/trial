Initial Setup – React Student Management System
Step 1: Create a React project
Open the VS Code terminal and run:

npm create vite@latest student-management -- --template react

Step 2: Select options
Linter: ESLint

Install with npm and start now: Yes

Step 3: Open the project folder
If the project setup finishes, open a new terminal and execute:

cd student-management
code .

Step 4: Install dependencies
npm install
npm install react-router-dom

Step 5: Edit App.jsx
Open the src folder.

Open App.jsx.

Replace the existing code with the Student Management System code.

Save using Ctrl + S.

Step 6: Run the application
npm run dev

Step 7: View the output
Open the local URL shown in the terminal, usually:

http://localhost:5173/
Result: The React application is ready, with Register, Login, Contact, and About pages connected through React Router.
